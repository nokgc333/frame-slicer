# ADR-0001: HTTP に標準ライブラリの `urllib` を使う

- ステータス: 採用（2026-10-19）
- 関連: [ADR-0003](0003-retry-only-failures-that-leave-no-job.md)

## 背景

QueueWatch への通信は、JSON の POST と GET だけ。
このツールは、パイプラインのマシンに入れて使う。
実行時の依存が少ないほど、入れやすく、脆弱性の監視も軽い。

## 決定

HTTP は標準ライブラリの `urllib` で行う。
実行時の依存は Click だけにする。

## 結果

- 良い点: 依存が増えない。`pip-audit` の対象が小さい。
- 良い点: リダイレクトを辿らない処理を、`HTTPRedirectHandler` の差し替え 1 つで書けた。
- 悪い点: 接続と読み取りのタイムアウトを分けられない（1 つの値 5 秒）。
- 悪い点: 再送、`Retry-After`、応答サイズの上限を、自分で書く必要があった（`transport.py` に集約し、実際のローカルサーバーでテストしている）。

## 検討した代案

- `requests`: 書く量は減るが、依存が増える。このツールの用途では、得るものが小さい。
- `httpx`: 同上。非同期は要らない。
